

# Personal CV & Portfolio Website

A responsive personal CV and portfolio website showcasing professional experience, technical skills, and selected development projects.

## Overview

This project is a personal portfolio website designed to present professional information and development work in a clean, modern, and accessible format.

The website supports both Hungarian and English, allowing visitors to switch between languages. It also includes theme customization and interactive elements to improve the browsing experience.

## Features

- **Bilingual interface:** Hungarian and English language support.
- **Responsive design:** Layout adapts to different screen sizes.
- **Theme customization:** Switch between available visual themes.
- **Project portfolio:** Displays selected development projects.
- **Project categories:** Organizes projects into categories.
- **Animations:** Includes interactive visual effects and transitions.
- **CV access:** Provides access to the downloadable PDF CV.
- **Print support:** Allows visitors to print the CV.
- **Deployment:** Hosted using Vercel.

## Technologies

## Running Locally

Clone the repository:

```bash
git clone https://github.com/Laca1234/new_cv.git
cd new_cv
```

The website uses standard HTML, CSS, and JavaScript, so no package installation or build process is required.

You can open `index.html` directly in a browser.

Alternatively, start a local development server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

The website can be customized by editing:

- `index.html` – Main page structure and content.
- `style.css` – Layout, styling, themes, and responsive design.
- `script.js` – Language switching, interactions, and project data.
- `assets/` – Images and other visual resources.
